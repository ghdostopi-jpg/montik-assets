# Montik asset library

Sound effects, stickers and motion graphics for Montik video projects.

- `sfx/` – sound effects, sorted by type
- `stickers/` – images and animated stickers
- `motion/` – motion clips and overlays
- `catalog.json` – every asset with its tags, length, source and license
- `LICENSES/` – the license of each collection

Only openly licensed material (CC0, MIT, CC BY) goes in this repo, because it is public.

## Inspiration (look, don't copy)

Collections we study for ideas. They have no open license, so none of their files or code go in this repo; we build our own versions.

- [ali-abassi/remotion-templates](https://github.com/ali-abassi/remotion-templates): 1,000 Remotion templates in 100 families. Most useful for ads: ad-vertical, creator-ugc, ecommerce-ads, sale-promos, quotes-testimonials, testimonial-cuts, stats-counters, outro-endcards, ui-annotations, kinetic-typography.
